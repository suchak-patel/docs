## Planned Site Structure

| Section | What it will cover |
|---------|--------------------|
| Study materials | Certification study guides, topic notes, and practice material |
| Personal projects | Project-specific docs, design notes, and walkthroughs |
| Reference | Shared technical references and evergreen notes |
| Shared | Reusable guidance that applies across collections |
| Archive | Retired or superseded pages kept for history |

# Documentation Governance

This site is docs-first and will be published with MkDocs Material on GitHub Pages.

Core rules:

- Start with governance and the relevant collection landing page.
- Organize content by collections, not by ad hoc folders.
- Keep every collection anchored by an `index.md` landing page.
- Use lowercase, kebab-case names and stable navigation paths.
- Update the nav and landing pages whenever content moves.

The canonical governance source remains the repo-root [documentation-governance.md](../../documentation-governance.md).

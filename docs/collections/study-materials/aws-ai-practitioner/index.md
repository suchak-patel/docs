## Key AWS Services Quick Reference

| Service | Purpose |
|---------|---------|
| **Amazon Bedrock** | Managed access to 100+ foundation models |
| **Amazon Bedrock Knowledge Bases** | RAG pipeline with managed vector store |
| **Amazon Bedrock Agents** | Agentic AI — orchestrates FM + APIs + data |
| **Amazon Bedrock Guardrails** | Content safety and privacy filters |
| **Amazon SageMaker** | Custom model training, deployment, MLOps |
| **Amazon Q** | Enterprise GenAI assistant |
| **Amazon Rekognition** | Image and video analysis |
| **Amazon Comprehend** | NLP — sentiment, entities, language detection |
| **Amazon Textract** | Extract text and data from documents |
| **Amazon Transcribe** | Speech-to-text |
| **Amazon Polly** | Text-to-speech |
| **Amazon Lex** | Conversational chatbots (voice + text) |
| **Amazon Kendra** | Intelligent enterprise search |
